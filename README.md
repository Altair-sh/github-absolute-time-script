# github-absolute-time-script
Tired of seing "released last year" on github instead of exact date and time? This script turns every relative timestamp into absolute.

## Installation
1. Download [`github-absolute-time.js`](./github-absolute-time.js)
2. Install Violentmonkey/Tampermonkey/any script loader addon for your browser.
   [Firefox addon](https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/)
   [Chrome addon](https://chromewebstore.google.com/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag)
3. Open addon menu and click "create script"
4. Select `github-absolute-time.js` and click "save script"
